# NFC Lock · 公开讨论与演示

GitHub Pages 从 main 根目录发布。这个仓库只维护公开页面产物；开发源文件和项目资料在私有开发仓库中维护。新增 Demo 使用独立子目录，不需要新建仓库。页面仅用于讨论和模拟，不提供实际设备控制或业务授权。
