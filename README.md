# NFC Lock · 公开讨论与演示

[页面目录](https://d-dai1984.github.io/nfc-lock-review/demos/)

- `role-flow/`：角色权限与工作流程讨论页（第 4 版；`role-flow-v3-2026-10-19.html` 为第 3 版历史副本）。
- `data-architecture/`：数据与通信架构 v0.3 阶段结论（默认用云、船舱内离线作业、延时扫码、人员扫码注册、容量与云选型，含待确认问题）。
- `asset-register/`：舱室与配电柜台账 Demo，`#mobile` 为手机现场端。
- `index.html`：保留最早分享的角色讨论页入口，内容与 `role-flow/` 同步为第 4 版。

GitHub Pages 从 main 根目录发布。这个仓库只维护公开页面产物；开发源文件和项目资料在私有开发仓库中维护。新增 Demo 使用独立子目录，不需要新建仓库。页面仅用于讨论和模拟，不提供实际设备控制或业务授权。
